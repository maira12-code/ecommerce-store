# 🛍️ NexStore PRO | Premium E-Commerce Store (Web & Mobile App)

A modern, feature-packed **E-Commerce Web & Mobile Application** built with React 18, Vite 5, Lucide Icons, and custom HSL design tokens.

---

## 🌟 Key Features

- 🛍️ **Interactive Catalog & Filters**: Instant search, category filters (Electronics, Fashion, Home, Sports, Accessories), max price slider, rating filter, and sorting.
- 📦 **Product Details Modal**: High-res images, stock indicators, size & color swatches, specs breakdown, and customer review counts.
- 🛒 **Slide-Out Shopping Cart**: Live quantity controls, free shipping progress bar, promo code system (`SAVE20` for 20% discount), subtotal, tax, and total calculation.
- 💳 **Checkout & Invoice Receipt**: Address form, payment option simulator (Credit Card, Apple Pay, Cash on Delivery), and printable/downloadable order receipt.
- 🚚 **Order Tracker**: Real-time delivery status timeline tracking (`Placed` ➔ `Processing` ➔ `In Transit` ➔ `Delivered`).
- 📱 **Mobile UI Emulator Frame**: Switch between desktop layout and an interactive **Android Device Frame**.
- ➕ **Admin Product Manager**: Add custom products directly to the store catalog.

---

## 🚀 How to Run Locally

1. Navigate to the project directory:
   ```bash
   cd ecommerce-store
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the dev server:
   ```bash
   npm run dev
   ```
4. Open the displayed URL in your web browser (e.g. `http://localhost:3001`).
